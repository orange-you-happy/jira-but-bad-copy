./gradlew bootRun in my-backend to run backend
npm start in my-frontend to run frontend

backend:
we have task.java, taskrespository.java, and taskcontroller.java, 
task is the actual task,
taskrepository is the link to the database and lets you do stuff with a database
taskcontroller manages how you access the thing

frontend:
logic in app.js

database:
http://localhost:8080/h2-console to look at the database
